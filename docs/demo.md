# Données de démonstration

Les captures présentes dans ce dépôt utilisent des valeurs fictives afin de présenter l'expérience utilisateur sans exposer de données réelles.

Exemples de valeurs visibles :

- 12 alertes ouvertes
- score de sécurité 78/100
- 48 ressources analysées
- 1 compte AWS connecté

Ces chiffres ne constituent pas une mesure d'un environnement AWS réel.
