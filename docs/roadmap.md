# Roadmap

## Court terme

- améliorer la fiabilité de la collecte multi-régions
- enrichir les règles IAM, S3, EC2, RDS et VPC
- ajouter des détails de remédiation aux findings
- améliorer la gestion des erreurs de permissions
- renforcer le calcul de couverture

## Moyen terme

- authentification cross-account par AssumeRole
- gestion de plusieurs comptes AWS
- historique comparatif entre scans
- export PDF / JSON / CSV
- support PostgreSQL
- conteneurisation complète

## Long terme

- multi-cloud
- moteur de politiques configurable
- intégration CI/CD
- API publique
- notifications et workflows de remédiation
- mapping vers CIS AWS Foundations et autres référentiels
